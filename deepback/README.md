# DEEPBACK — город на спине Матери

3D-прототип кооперативного рогалика на выживание (пока одиночный режим). Three.js, работает в браузере без сборки.

## Запуск

```bash
cd deepback
npm start            # http://localhost:8000
```

Нужен Node.js 20+. Модули ES нельзя открыть через `file://`, поэтому игра запускается через мини-сервер `tools/serve.mjs` (подойдёт и любой другой статический сервер).

Игра рассчитана на компьютер: клавиатура и мышь.

## Тесты

```bash
npm install          # three.js для модульных тестов
npm test             # всё
npm run test:unit    # модульные: форма кита, экономика, город, физика, существа, задания
npm run test:e2e     # сквозные в Chromium: полный игровой цикл, финалы, сохранения, пауза
```

Для сквозных тестов нужен Playwright с Chromium (`npm i -D playwright && npx playwright install chromium`).
В GitHub Actions тесты запускаются автоматически (`.github/workflows/deepback-tests.yml`).

## Что уже есть

- Кит-остров с городом, который генерируется заново каждый день.
- Вода поднимается за день; в конце Мать ныряет. Кто не у шлюза Ковчега — тонет.
- Рыба (у краёв, затапливается первой) и бочки ворвани (тяжёлые, замедляют).
- Жители Ковчега едят и жгут ворвань каждую ночь; нехватка — смерти.
- Пиявки со 2-го дня срывают груз.
- Дыхало периодически выбрасывает фонтан и подкидывает игрока.
- Плавание, кислород, подводный туман и звук.
- 7 реликвий с сюжетом и 3 финала.
- Обломки и мастерская Ковчега: 6 улучшений между днями (короб, баллон, ласты, сапоги, гарпун, коптильня).
- Гарпун (F) отталкивает пиявок и отпугивает глубинников.
- Глубинники — светящиеся подводные хищники (со 2-го дня), кусают и отнимают кислород.
- Сохранение в летописи Ковчега и кнопка «Продолжить» в меню.
- 8 жителей Ковчега с именами и историями: каждый день кто-то просит принести припасы или найти потерянную вещь; погибших называют по именам.
- Погода: ясно, штиль (вода поднимается медленнее), туман (видимость десятки метров), шторм (волны, дождь, молнии, ветер, короткий день).
- Меню паузы (Esc/P): громкость, чувствительность камеры, инверсия, выход в меню.
- Предыстория из 5 слайдов перед первым днём (кто ты, как оказался Ныряльщиком, что делать); в меню её можно перечитать.
- Мини-карта с легендой: спина Матери сверху, уровень воды, постройки, Ковчег, припасы, реликвии, пиявки, глубинники, маршрут.
- Навигатор: пунктир на земле ведёт к цели в обход домов (A*). Tab переключает цель: Авто, Ковчег, Рыба, Ворвань, Обломки, Реликвия, Просьба жителя, Выключен.
- Процедурный звук (WebAudio), смена дня и сумерек.

## Ночь в Ковчеге

После сводки ночи — «Войти в Ковчег»: зал под ржавым куполом с печью, фонарями и иллюминаторами, за которыми проплывает что-то огромное. Ходишь как днём, E — подойти и поговорить.

- **Механик Тагир** (верстак) — улучшения снаряжения за обломки.
- **Бран Молчун** (оружейная стойка) — оружие против пиявок:
  - костяная острога — гарпун (F) убивает пиявок, а не отталкивает;
  - солевые бомбы ×3 — G, бросок метров на шесть, убивают пиявок в радиусе 4,5 м и отпугивают глубинников;
  - ракетница — Q раз в день: прогоняет глубинников, пиявки вокруг засыпают.
- **Советник Оск** (летопись) — сохранение. Игра сохраняется только здесь; перед сном без записи игра переспросит.
- Остальные жители разговаривают, у некоторых — полезные подсказки (Агата предсказывает погоду на завтра).
- Погибших жителей в Ковчеге больше нет; безымянные жители спят в гамаках. Если хозяин мастерской или оружейной погиб, станция работает сама.
- Лечь спать в своём гамаке — начать следующий день.

## Графика

- Океан на шейдере: волны на видеокарте (совпадают с физикой плавания), отражение неба по Френелю, солнечные блики, рябь, бирюзовое мелководье над спиной Матери, пена у кромки.
- Небо с солнцем, ореолом заката, облаками и луной; солнце движется в течение дня.
- Процедурные текстуры без файлов-картинок: доски, черепица, ржавый металл с заклёпками, морщинистая влажная кожа Матери.
- Освещение от неба (карта окружения), мягкие тени, свечение огней (bloom), цветокоррекция и виньетка, сглаживание SMAA.
- Живой мир: чайки, дым из труб, флажки и бельё на верёвках, брызги прибоя, луч маяка на Ковчеге; под водой — пузыри, взвесь и лучи света.
- Ныряльщик в латунном шлеме с иллюминаторами, баллонами и тяжёлыми ботинками.
- Неподвижные постройки склеиваются в несколько сеток — десятки отрисовок за кадр вместо тысячи.
- Качество графики в меню паузы: авто (по умолчанию — начинает с высокого и снижает, если кадров меньше 25 в секунду), высокое, среднее, низкое. Стартовое значение можно задать в адресе: `?quality=low`.
- Главное меню — поверх живой панорамы города.

## Озвучка

Рассказчик озвучен в ElevenLabs (голос «Aleksandr — Documentary Narrator»). Файлы — `audio/vo/*.mp3`,
список и длительности — `src/voice.js`. Если файла нет, фраза просто остаётся субтитром.
Громкость голоса настраивается отдельно в меню паузы.

Озвучены: все 8 фраз вступительного ролика и записи реликвий 2–5. Реликвии 1, 6, 7 и три финала
пока без голоса: бесплатный тариф ElevenLabs был отключён во время генерации.

## Музыка

Генеративный эмбиент на WebAudio, без файлов: медленные минорные аккорды с эхом. Ночью музыка
темнеет, под водой — глохнет. Громкость — отдельный ползунок в паузе.

## Управление

WASD — ходьба, Shift — бег, мышь — камера, Space — прыжок/всплыть, C — нырнуть,
E — подобрать/сдать/поговорить, F — гарпун (острога), G — солевая бомба, Q — ракетница, R — укрыться в Ковчеге, Tab — цель навигатора, M — мини-карта, J — журнал, Esc/P — пауза.

## Структура

- `src/whale.js` — форма кита и функция высоты спины (для физики).
- `src/city.js` — Ковчег, генерация кварталов, припасы, пиявки.
- `src/player.js` — движение, коллизии, плавание.
- `src/ocean.js` — волны.
- `src/creatures.js` — глубинники.
- `src/upgrades.js` — улучшения мастерской.
- `src/audio.js` — синтез звука.
- `src/lore.js` — тексты сюжета.
- `src/residents.js` — жители, задания, погода.
- `src/economy.js` — экономика Ковчега и уровень воды (чистые функции).
- `src/nav.js` — поиск пути для навигатора (чистые функции).
- `src/minimap.js` — мини-карта.
- `src/cutscene.js` — сценарий вступительного ролика (сцены, камера, субтитры, события).
- `src/voice.js` — озвучка рассказчика.
- `src/graphics.js` — небо, солнце, пост-обработка и уровни качества.
- `src/textures.js` — процедурные текстуры.
- `src/ambient.js` — чайки, дым, пузыри, взвесь, лучи света.
- `src/ark.js` — Ковчег изнутри: зал, жители, станции.
- `src/armory.js` — оружие (чистые функции).
- `tools/serve.mjs` — сервер статики.
- `tests/` — модульные (`unit/`) и сквозные (`e2e/`) тесты.
- `src/main.js` — игровой цикл, день/ночь, интерфейс.
