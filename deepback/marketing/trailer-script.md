# Трейлер DEEPBACK — сценарий

Формат: YouTube, 1:20. Всё снимается на движке игры.
Голос: рассказчик игры (тот же тон, что во вступительном ролике), без обращения «ребята», без интро канала.
Аудитория: игроки, которые любят атмосферные инди — Outer Wilds, Subnautica, Lethal Company.

## Хуки

Оценены скриптом `hookscore.py` из навыка `/yt-script`. Скрипт понимает только английский, поэтому
оценивались английские эквиваленты — цифры ориентировочные. Все факты в хуках взяты из игры:
первый день длится 2:50, шесть погибших городов — часть сюжета.

**Хук A — победитель, 72 (STRONG), формула «Предупреждение»**

> Прежде чем выйти наружу, запомни: до тебя здесь жили шесть городов. Ни один не дожил.

```
SPECIFICITY  ~   STAKES  ~   ADDRESS  ~   CURIOSITY (самое слабое)   BREVITY 100
VERDICT 72 STRONG · The Warning
```

**Хук B — 70 (WORKABLE)**

> У тебя меньше трёх минут, пока город не ушёл под воду. Почему он всплывает снова — не знает никто.

```
VERDICT 70 WORKABLE · слабое место: SPECIFICITY
```

Почему A: предупреждение сразу ставит зрителя на место героя («запомни»), даёт конкретную ставку
(шесть мёртвых городов) и открывает вопрос, на который отвечает только игра — почему они погибли.
Это ровно то, на чём держатся Outer Wilds и Subnautica: тайна мира важнее механики.

## Хронометраж

Голос — около 120 слов, при 150 словах в минуту это ~48 секунд речи. С паузами под музыку и
монтажные склейки — 1:20.

## Что нужно для съёмки

- Сцены 0:00–0:34 уже есть во вступительном ролике игры — их можно записать прямо с экрана.
- Монтаж геймплея 0:34–0:58 — запись игры с выключенным интерфейсом.
- Голос рассказчика и музыка — пока нет; песню Матери можно взять из игры (она синтезируется).
