# Навыки проекта

YouTube-навыки из [Jakeschincariol/youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill)
(коммит `a2feb21`, лицензия MIT — см. `LICENSE-youtube-agent-skill`).

Изменение относительно оригинала одно: навыки сначала ищут профиль стиля в проекте,
в `.claude/youtube/voice.md`, и только потом в `~/.claude/youtube/voice.md`. Так профиль
сохраняется в репозитории и доступен в облачных сессиях, где домашняя папка каждый раз новая.

Перед добавлением скрипты проверены: только стандартная библиотека Python, файлы
читаются и не изменяются, сетевых запросов и запуска команд нет.

| Навык | Что делает |
|---|---|
| `/yt-script` | сценарий с вариантами хука и их оценкой |
| `/yt-package` | название и обложка вместе |
| `/yt-edit` | список правок для монтажа по расшифровке |
| `/yt-comment` | разбор комментариев и черновики ответов |
| `/yt-plan` | план видео на неделю или месяц |
| `/yt-viral` | видео в нише, которые сработали лучше обычного для своего канала |
| `/yt-retention` | разбор графика удержания |
| `/yt-shorts` | нарезка Shorts из длинного видео |
| `/yt-seo` | описание, теги, поисковые запросы |
| `/yt-chapters` | тайм-коды глав |
| `/yt-audit` | аудит канала |
